# v0.4.0-rc5 — query pagination and reliable local imports

This prerelease fixes three RC4 defects without adding an editor, storage, collaboration, host-canvas injection or business writes:

- Reaching one operation's pagination limit records that operation's partial result without stopping unrelated queries. Actual capability-wide exhaustion still stops subsequent calls; truncated dependencies and missing required outputs remain blocked.
- Invalid display-field types fail at import validation. A synchronous render failure restores the original DOM nodes, source, directory, selection, focus and viewport state. Failed-render animation callbacks cannot affect later imports.
- Each import captures its File and revision; stale success, failure and finally handlers cannot overwrite a newer import or clear its pending input.

The viewer remains read-only with `connect-src 'none'`, local JSON only, no upload/CDN/evaluator and no invented execution traces. Unknown string Hit Policies remain explicit diagnostics rather than inferred policies.
