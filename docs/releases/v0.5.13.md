# v0.5.13

- Add five policy-table names as read-only aliases of the current names: `target.scene.entity` → `target.scene_entity`, `triage.scene.acceptance` → `triage.acceptance`, `triage.supplement.requirements` → `supplement.requirements`, `triage.dispatch.route` → `dispatch.route`, `triage.dispatch.resource` → `dispatch.resource`.
- Reading a new name (table, history, version, `evaluate_stored_table`) reads the current name's storage and reports `alias_of`; saving under a new name is refused with `STORED_TABLE_ALIAS_READ_ONLY`.
- Alias save requests and persisted relationship fields are rejected; resource-in-use and route-removal guards also recognize preexisting aliased resource references.
- Malformed table names remain validation errors. Reads fail closed on a preexisting physical alias-table collision; no stored data is migrated or overwritten.
- Canonical table names retain their existing behavior.

Production installation and acceptance have not been completed.
