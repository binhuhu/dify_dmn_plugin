# v0.5.2（已发布，2026-10-23 UTC）

Historical version record. Test counts and validation status below describe that version, not the current review branch or a current deployment.

## 已知限制与接入边界

- 并发覆盖问题本版未修复，且在精确发布源码上再次复现：两个写入者创建同一缺失版本时可同时成功，后者覆盖版本记录和 head，前者不保证收到 409；各自不可变副本仍保留。不能宣称并发安全。
- 本版需要另建并发布维护应用、配置端点 `store_app_id`；留空仍使用端点自己的存储，仅适合本地调试。
- 能搭流程或运行维护应用的工作空间成员可经 `route_table_store` 修改路由；编辑口令只保护编辑页。
- 本发布任务未安装 目标工作空间、未执行 Dify 宿主 或目标宿主联调。目标宿主接入需要独立验证。

## 修复

- 编辑页与结构查看器原先都声明根 GET 路由。编辑器从本版挂到 `/routes/`（含 `/routes` 跳转），避免 GET 被结构查看器接收。`test_endpoint_routing.py` 按 SDK 路由表方式覆盖该冲突。
- 端点与工具存储可能隔离。新增 `route_table_store`，编辑端点可通过 `store_app_id` 调维护应用，在工具存储中读写。`test_route_store.py` 用两份隔离存储验证保存后决策工具能够读取。

内置工具变成 7 个，最后一个是 `route_table_store`。版本号 0.5.2（manifest、`scripts/stage-builtin.py`、兼容脚本和测试里的版本断言）。

合同、维护应用的搭法和退路见 [route-table-editing.md](../route-table-editing.md)「Dify 宿主 上：端点的存储 ≠ 工具的存储」。
