# v0.5.1（已发布，2026-10-23 UTC）

Historical version record. Test counts and validation status below describe that version, not the current review branch or a current deployment.

## 已知问题：并发保存不保证冲突检测

本版保留原始源码提交 `911c3386f4c33a9afcd7e4979453b76706f848f9`。发布前已复现：两个写入者同时创建同一个尚不存在的版本时，双方都可能返回成功；后写入者会覆盖该版本记录和当前 head，先写入者不保证收到 409。两份 `:s:<save_id>` 不可变副本仍保留。本版没有修复此问题，不能视为并发写入安全。

Known issue: concurrent writers creating the same missing version can both succeed. The later writer overwrites the version record and head; the first writer is not guaranteed a 409. Immutable save copies remain. This release does not fix the defect or guarantee safe concurrent writes.

| 编号 | 问题 | 改了什么 |
|---|---|---|
| 回归项 | 编辑页保存没有确认；冲突后照提示刷新会丢草稿；导出导的是已存版本；报错不定位到行 | 保存分两步：先列出和现存版本相比的改动（去向、方案登记、场景目录）并在页面上挡住必错的路由，「确认保存」才写；409 时草稿保留，「载入最新版并保留我的改动」把自己的改动重放到最新版上；可导出编辑区；`error.path` 的 `routes[i]` 定位并标红那一行 |
| 编译回归 | v1 路由编译 | 仓库中保留合成与冻结基线的编译对照测试；外部部署数据不构成公共验收。 |
| 回归项 | 两个人同时保存会拿到同一个版本号，其中一版从历史里消失 | 每次保存带 `save_id` / `parent_save_id`，先写永不覆盖的 `:s:<save_id>`；第 n 版已被占用就 409 `ROUTE_TABLE_STALE`；写完读回版本和当前版，不是自己的就 409 `ROUTE_TABLE_RACE` |
| 回归项 | 工具存储接线和编辑页需要自动测试 | `evaluate_decision` 工具带假 session 读插件存储的测试；编辑页 6 个 jsdom 测试（`viewer/tests/route-editor.test.cjs`，CI 的 Viewer browser 工作流 `npm test` 会跑） |
| 格式边界 | 知识库路由规模可能超过路由表上限 | v2 表只收 `SOLUTION_APP` 和 `TRANSFER`，知识库去向报 `ROUTE_TABLE_TARGET`；决策数据去掉知识库三个字段；编辑页去掉知识库选项。v1 不变 |

v2 决策数据的字段因此变成：`route_state`、`route_kind`、`app_id`、`solution_name`、`solution_inputs_json`、`transfer_to`。调用方迁移需单独验证。
