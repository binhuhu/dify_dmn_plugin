# v0.4.0-rc3 — read-only viewer usability

Phase → actual Step → Node remains the source of membership. This prerelease adds a collapsible searchable directory, rule ID navigation, grouped input/state/data/actions tables with sticky headers and rule IDs, persistent hit policy, directed edge selection, 100% / Fit Step / Fit All controls, normal wheel scrolling and modifier zoom, and mobile node lists with full-screen details. Original rule JSON and template references remain available without evaluation. Missing templates explicitly warn without inline fallback; missing/unknown hit policies are not inferred. Empty workflows clear scope and transforms. Imports show filename and actual structure counts; failed imports retain the previous graph and label its source. Diagnostics navigate to their node/rule. Closing details restores focus.

Delivered UI remains five local static files served by the plugin Endpoint. CSP keeps `connect-src 'none'`. No CDN, remote loading, browser storage, workbench/editor/collaboration, host-canvas injection or fabricated runtime trace is added. Only public synthetic data is used in verification.

Validation: **665 Python**, **99 Node**, **9 adapter + 5 DOM** tests; Python lint/format passed. Official CLI **0.6.10** packaged the candidate, and all **49 archive files** matched staging byte-for-byte (`.env.example` is omitted by CLI packaging). Unpacked package passed **6 Endpoint** calls with exact static bytes, **14 legacy tool** calls and **6 node tool** calls through the real SDK. Manifest remains `hu8627/dmn_json`, version `0.4.0-rc3` (CLI-compatible suffix).

Package: **88,888 bytes**, SHA-256 `e68c0a66fda9afddaa547183d1247806541174391af34cfd120d4dff600d108f`. The GitHub prerelease records the exact feature source SHA and main merge SHA; the asset filename includes the source short SHA. Existing tags/releases/assets are preserved.

**Not verified:** normal sandboxed Chromium aborts before loading the page because the SUID helper is misconfigured. Screenshots, pixel layout, real browser interactions and observed network isolation are therefore NOT_RUN. The DOM suite is not browser acceptance. No sandbox/TLS bypass was used. Target Dify installation/upgrade, production APIs and real business acceptance remain NOT_RUN. Upstream SDK emits gevent/Pydantic deprecation warnings during passing tests.
