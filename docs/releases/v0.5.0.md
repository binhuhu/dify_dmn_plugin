## 安装时会多问的权限

| 权限 | 用途 |
|---|---|
| `storage`（16 MiB） | 路由表和它的历史版本 |
| `endpoint` | 路由表编辑页（0.4.2 已有，用于结构展示页） |
| `app` | `invoke_solution` 调本工作空间里已登记的方案应用 |

## 打包（发布者执行，同 0.4.2 的做法）

1. 推送 main，确认 GitHub 上 Checks 对发布提交是绿的。
2. 从该提交的干净 `git archive` 运行 `python scripts/stage-builtin.py <staging 目录>`，再用官方 Dify CLI 打包：`dify plugin package <staging 目录> -o hu8627-dmn_json-0.5.0.difypkg`。
3. 打 annotated tag `v0.5.0` 指向该提交，发 GitHub Release，唯一资产是上面的包；记录包大小、SHA-256、Dify checksum 和插件身份 `hu8627/dmn_json:0.5.0@<checksum>`。
4. 在 AgentHub 的 ESE_sd 工作空间把 `dmn_json` 从 0.4.2 升级到 0.5.0（From GitHub），同意新增权限；新建「路由表编辑」端点并填编辑口令。
