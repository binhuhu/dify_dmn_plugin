# v0.5.18

- Adds grouped `when_any` conditions and per-combination traces for stored decision tables.
- Includes the v0.5.17 stored-table naming, disposal declaration, segmented text and per-hit output changes.
- Hardens agent-only text validation, runtime rule identifiers and solution table name matching.

Inline models are unchanged. Grouped conditions, solution-layer names and per-hit outputs require v0.5.18; older versions cannot consume them directly. Before downgrading, switch callers to compatible definitions or pinned earlier table versions. Keep stored data intact; downgrading software does not migrate it.

Row-order overlap warnings use bounded conservative analysis. `shadowing_analysis_limited` marks unresolved pairs reported as possible overlaps.

This release does not install or change a running service. Live installation and rollback are not verified.
