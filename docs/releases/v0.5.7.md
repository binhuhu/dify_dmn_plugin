## 编辑页保键：0.5.5 起就有

路由表编辑页（`plugin/route_editor_static/editor.js`）**从 0.5.5 起就保留 `resource_table` 和载入文档里的每一个键**：
`toDoc` 从 `structuredClone(d.base)`（载入的整份文档）出发，只覆盖 `schema / table / routes / note`；`issue_types / phases / scenes / solutions` 只在改过时才换；没改的路由行原样带回（0.5.5 `200e56b`，WO-72）。0.5.6 沿用，v3 表也走同一条路（「升为 v3」只动 `schema` 与方案登记）。服务端 `route_store.run_op` 的 v2 / v3 键含 `resource_table`，存储层原样保存。
所以「编辑页存表丢 `resource_table`」在现网（0.5.6）已经不成立；0.5.7 不改 `editor.js`。
canon 探针 `config/route_table/probe/route_editor_drops_resource_table` 是字面检查（`toDoc` 函数体里没有字样 `resource_table` 就判丢），对 0.5.5 / 0.5.6 / 0.5.7 都是误报；改成行为检查归 V3 的 canon 主人（WO-94）。
