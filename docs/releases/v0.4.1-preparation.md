## Migration

Dify node configuration now has four fields: `definition_bundle_json`, `node_ref`, `inputs_json`, `execution_context_json`. Remove the obsolete fixed pin from workflows. Direct Python integrations must remove the former third positional argument / `expected_definition_sha256` keyword; the old five-argument Python call is incompatible. Do not remove `QueryDeployment.definition_sha256` or host authorization. An extra old SDK pin does not provide validation. Legacy three tools retain their contracts.

The offline shadow-input.v1 archive retains its checksum contract. Its adapter verifies the archived definition checksum before calling the four-argument evaluator. Original specification and historical evidence are not rewritten as new acceptance. The existing root checksum inventory was regenerated for current files.
