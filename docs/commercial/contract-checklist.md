# 商业合同要点（谈判草案）

本清单用于准备 Brian Hu 与客户之间的合同及交付附件，不是商业许可证、报价单或已签合同。具体条款、生效条件、签署方式与法律适用需要在正式签约前完成审查。

| 条款 | 需填写和核验的内容 |
| --- | --- |
| 当事人及签署权限 | Brian Hu 的真实签约/收款信息；客户法律主体及代表权限；不编造公司主体 |
| 授权标的 | 组件、版本、源码提交、安装包/镜像摘要、源代码或目标代码范围；排除第三方清单 |
| 权利链 | 原创来源、共同作者/雇主权限、CLA 证据；哪些权利由 Brian Hu 有权授予 |
| 授权范围 | 运行、复制、修改、集成、内部部署、OEM 分发、再许可和托管分别列明；禁止只写“无限商用” |
| 计量与期限 | 法律主体/关联方、产品、实例/环境、租户或其他计量方式；地区、期限、续期规则 |
| AGPL 与第三方 | 仅替代合同明确覆盖的项目权利条件；依赖保留原许可、声明和源码义务；客户既有 AGPL 权利不撤回 |
| 费用及税务 | 报价、币种、税费、付款节点、许可生效、增购/续费/退费；均待双方约定 |
| 交付与验收 | 材料、渠道、签名、兼容环境、功能、测试用例、期限与不通过处理；源码获取方式 |
| 维护与 SLA | 支持版本、渠道、时区、响应目标、修复范围、升级是否包含、停服/到期安排；不预设可用性承诺 |
| 客户资产与保密 | SOP、业务规则、数据、定制成果各自归属；允许使用范围；机密交换方式 |
| 数据及部署 | 数据处理角色、地点、保留/删除、访问控制、事件通知；不默认获准处理生产数据或执行写操作 |
| 保证与责任 | 可承诺的权利/功能范围、依赖与客户修改排除、责任限制、赔偿或替换机制；须适用当地法律 |
| 终止与续存 | 违约通知/补救、到期后使用和分发权、数据/源码材料处理、存量客户安排；AGPL 权利独立处理 |
| 法律与争议 | 适用法律、争议解决、通知渠道、语言、签署方式；本清单不擅自指定司法辖区 |

交付附件至少包含：授权组件清单与第三方排除、精确源码与摘要、部署/依赖材料、明确验收用例、技术支持矩阵、已知限制及客户责任。合同中应区分“许可权利已生效”和“某项服务/功能已验收”。编辑、版本治理和真实履约只有在对应迭代实际实现并通过约定验收后才能列为已交付。
