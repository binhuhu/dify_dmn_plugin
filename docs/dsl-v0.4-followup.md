## 可信宿主接线门槛

生产查询至少需要宿主在读取前核验：固定发布定义、当前节点实例确实激活、当前尝试未终结、所需意图已选中、租户与主体身份、当前读取授权及撤销状态。请求中的 `activation_ref`、`approved`、摘要或未过期签名不能单独满足这些条件。

不新增臆造的 token 授权服务。Python 注入适配器只能由受信任部署代码创建，不能从工具 JSON 指定模块或回调。默认 SDK 缺少上述生产接线时应拒绝生产读取；本地 SYNTHETIC loopback 协议测试必须明确其范围。

纯决策仍允许无凭据离线重放，保持 `CONTENT_ONLY_NOT_AUTHORIZATION`；不能把该结果直接用于真实派发。旧三工具与 `json-table-v1` 运算语义不变。

## 后续状态边界

PENDING/UNKNOWN 可以沿显式端口进入 WAIT，但经过 MERGE 不能被提升为成功；JOIN/业务 END 检查尚未完成状态。合法 WAIT 回执解除相应状态后才可完成分支。嵌套失败按登记 error 边收敛，部署拒绝失败路径新增执行或等待；不隐式改跳父网关。
